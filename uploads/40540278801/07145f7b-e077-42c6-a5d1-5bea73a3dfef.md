# 永登生态可视化系统技术总结

## 一、项目简介

### （一）项目**背景**

​	随着遥感技术的不断发展，其在资源调查、环境监测、城乡规划等领域的应用日益广泛。土地覆盖信息作为自然地理环境与人类活动的重要表征，在国土空间规划、生态环境评估等方面具有重要意义。通过对遥感影像的处理与分析，可以快速、准确地获取区域土地覆盖状况，提升资源管理的科学性和效率。

### （二）**项目目标**

​	本项目以“永登县土地利用与生态治理可视化辅助系统”为核心建设目标，致力于开发一套集数据处理、地图交互、区域分析和成果导出于一体的信息化平台，为地方生态修复、水土保持与空间规划提供智能支持与可视化决策依据。

### （三）**研究目标背景介绍**

​	永登县地处黄土高原边缘区域，地势起伏大、植被覆盖率低，土地资源开发压力大。近年来，在城市化推进和资源利用加剧的背景下，当地面临林地破碎、耕地退化、草地沙化、水土流失等多重生态问题，亟需精准、可视化的土地利用数据分析工具，为生态治理提供技术依据。

​	本项目将以Landsat 8等卫星遥感影像为主要数据源，辅以DEM地形数据和NDVI植被指数，构建多维土地利用评价模型。项目采用监督分类、地形分析和栅格叠加等方法，准确识别各类地表覆盖类型（如耕地、草地、裸地、建设用地、水体等），并基于坡度与植被状况进行生态风险区域识别。

​	在系统设计方面，项目拟开发一个桌面级或Web端交互式平台，实现遥感数据的加载、土地类型的分类展示、图表统计输出、高风险区标注及简报生成等功能，提升遥感成果的直观性与实用性。用户可在地图上查看土地利用结构，浏览区域统计图，筛选重点生态治理区，并一键导出PDF图表或报告。

​	此外，项目将结合实地调查验证遥感分类结果，采集典型地块的实景照片和地面信息，补充作物类型、植被覆盖、坡地利用方式等一手数据，提升系统的准确性与应用适应性。

​	本项目集成遥感处理、空间分析、界面开发与实地采样等多项技术实践，既能提升团队的跨学科工程能力，也将探索信息技术在生态治理中的落地路径，具有重要的科研训练价值和现实意义。

### （四）**研究内容**

获取并预处理覆盖永登县的遥感影像数据；

采用监督分类方法完成土地覆盖类型划分；

利用DVI植被指数计算与DEM坡度提取计算区域风险度；

生成土地覆盖分类图、风险度图，输出 GIS 成图成果；

利用数据库存储数据，建设可视化平台；

撰写技术报告，分析分类结果与应用价值。

#### **使用SCP插件通过光谱角度匹配法进行分类：**

​	光谱角度匹配法基于向量夹角原理，将像元光谱与参考光谱视为高维空间中的向量，通过计算两者之间的夹角来判断相似程度，夹角越小表示越相似。SAM 方法对光照强度变化不敏感，广泛应用于高光谱数据分析中。

优点：对光照、阴影等影响鲁棒性强，适合处理高光谱数据。
缺点：对光谱形状敏感，但对幅度差异不敏感，存在一定误判可能。

### （四）**土地风险评估**

#### **坡度图**

对下载的DEM图使用栅格工具中的坡度分析得到坡度图，并使用栅格计算器对坡度图重新赋值，赋值规则如下：

<5°：1（低风险）

<5-15°：2

<15-25°：3

<25-35°：4

\>35°：5（高风险）

#### **NVDI图**

通过栅格计算器按照公式NDVI = (NIR - RED) / (NIR + RED)计算得到NVDI图，对NVDI图标准化，输出为0到5

使用栅格计算器，按照坡度30%，NVDI40%，土地分类30% 的规则计算出土地风险图，得出的图是单灰度图，为方便看出土地风险程度，选择对不同值进行染色。

##### 2. 数据模型模块（models）

##### （1）空间数据类型支持

- 自定义`MultiPolygon`类型，完美适配 PostGIS 的 geometry 类型
- 实现`Scan()`和`Value()`方法，完成数据库与 Go 结构体间的 WKT 格式转换

```go
// 空间数据类型转换核心实现
// Scan 从数据库读取数据（WKT格式）并转换为 geom.MultiPolygon
func (m *MultiPolygon) Scan(value interface{}) error {
	if value == nil {
		m.MultiPolygon = nil
		return nil
	}

	// 数据库存储的可能是 []byte 或 string 类型的 WKT
	var wktStr string
	switch v := value.(type) {
	case []byte:
		wktStr = string(v)
	case string:
		wktStr = v
	default:
		return fmt.Errorf("不支持的类型: %T，无法转换为 MultiPolygon", v)
	}

	// 解析 WKT 为 geom 对象
	geomObj, err := wkt.Unmarshal(wktStr)
	if err != nil {
		return fmt.Errorf("解析 WKT 失败: %v", err)
	}

	// 断言为 MultiPolygon 类型
	mp, ok := geomObj.(*geom.MultiPolygon)
	if !ok {
		return errors.New("WKT 内容不是 MultiPolygon 类型")
	}

	m.MultiPolygon = mp
	return nil
}

// Value 将 geom.MultiPolygon 转换为 WKT 字符串存入数据库
func (m MultiPolygon) Value() (driver.Value, error) {
	if m.MultiPolygon == nil {
		return nil, nil
	}
	// 转换为 WKT 格式
	return wkt.Marshal(m.MultiPolygon)
}
```

##### 3. 路由模块（routes）

- 定义系统所有 API 接口路由
- 配置 CORS 跨域策略，允许指定前端域名访问
- 实现数据库连接的上下文注入，方便控制器层使用

```go
func SetupRouter() *gin.Engine {
	r := gin.Default()

	//添加 CORS 跨域中间件
	r.Use(func(c *gin.Context) {
		c.Writer.Header().Set("Access-Control-Allow-Origin", "http://localhost:63342")
		// 允许的请求方法
		c.Writer.Header().Set("Access-Control-Allow-Methods", "GET, POST, PUT, DELETE, OPTIONS")
		// 允许的请求头
		c.Writer.Header().Set("Access-Control-Allow-Headers", "Origin, Content-Type, Accept, Authorization")
		// 允许前端读取的响应头
		c.Writer.Header().Set("Access-Control-Expose-Headers", "Content-Length")
		// 允许携带 Cookie
		c.Writer.Header().Set("Access-Control-Allow-Credentials", "true")

		// 处理预检请求（OPTIONS 方法）
		if c.Request.Method == "OPTIONS" {
			c.AbortWithStatus(http.StatusNoContent) // 204 No Content
			return
		}

		c.Next() // 继续处理后续请求
	})

	dbConfig, err := config.LoadConfig()
	if err != nil {
		log.Fatalf("Failed to load config: %v", err)
	}
	db := dbConfig

	// 使用中间件注入数据库连接
	r.Use(func(c *gin.Context) {
		c.Set("db", db) // 将数据库连接保存到上下文中
		c.Next()        // 调用后续处理程序
	})

	r.POST("/pi/auth/register", controllers.RegisterUser)
	r.POST("/api/auth/login", controllers.Login)

	// 根据 Gridcode 获取数据
	r.GET("/api/riskusage/gridcode", controllers.GetRiskUsageByGridcode)
	r.GET("/api/risks/gridcode", controllers.GetRisksByGridcode)
	r.GET("/api/usages/gridcode", controllers.GetUsagesByGridcode)

	return r
}
```

		})

- 实现地图边界限制，防止用户浏览超出永登县范围的区域
- 采用 Canvas 渲染模式提升大数据量下的性能表现

##### 2. 数据可视化

- 土地类型可视化：通过不同颜色区分植被（绿色）、水体（蓝色）、裸土（黄色）、人工建筑（红色）
- 风险区可视化：通过颜色梯度展示极低、低、中、高四个风险等级
- 支持批量数据渲染队列，采用分批处理机制避免页面卡顿
- 实现 WKT 格式地理数据解析，支持多边形和多 polygon 类型

##### 3. 交互功能

- 图层控制：显示 / 隐藏全部土地类型、显示 / 隐藏所有风险区、清除图层
- 数据查询：单条件查询（土地类型 / 风险度）、组合条件查询
- 图片查看器：可展开 / 折叠的右侧图片面板，展示土地利用类型图
- 地图操作：缩放、平移、边界限制

##### 4. 辅助功能

- 图例说明：清晰展示各类土地类型和风险等级的颜色标识
- 消息提示：操作反馈和错误提示
- 调试日志：记录关键操作和错误信息
- PDF 下载：支持土地利用分类图和风险区分析图的下载

#### 3.性能优化策略

1. **数据分批渲染**：采用队列机制和 requestAnimationFrame 实现数据分批加载渲染，避免大量数据一次性渲染导致的页面卡顿
2. **图层管理**：维护图层数组，实现批量清除和精准控制
3. **图片错误处理**：为图片资源设置错误处理机制，加载失败时显示占位图
4. **边界限制**：限制地图最大 / 最小缩放级别和移动范围，减少不必要的资源加载
5. **按需加载**：根据用户查询条件加载对应的数据，避免一次性加载全部数据
